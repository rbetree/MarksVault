# Triage 标签

工程 skills 使用五个 canonical triage 角色。下表将角色映射到本仓库实际使用的
GitHub label。

| Skill 中的角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整说明，可由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提及某个 triage 角色时，使用表中对应的 GitHub label。若仓库以后修改
标签名称，应同步更新右侧映射。
